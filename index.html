NeuroDB v2.0

High-Performance In-Memory Graph Database Engine

Get Started →

🚀 Lightweight

Core engine only 400KB, extremely lightweight with minimal resource consumption

⚡ High-Speed In-Memory

Full in-memory data operations, eliminating disk I/O bottlenecks with exceptional query performance

🔌 Embeddable

SQLite-like embedded architecture, no separate deployment required, easily integrated into applications

🎯 Replication Cluster

Supporting a one-master-multiple-slave architecture for high data availability and read-write separation

🌐 Cross-Platform

Supports Windows, Linux, macOS, mobile platforms and embedded systems (like STM32), truly cross-platform compatible

🏗️ Graph Modeling

Visual client supports object-oriented graph data modeling with structured and typed properties for nodes and relationships
